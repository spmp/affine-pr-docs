# pr/30: Mobile keyboard toolbar: placement and database tools

## Why

On iOS in mobile Safari and the installed PWA, the editor's keyboard toolbar
often sits in the wrong place:

- floating above the keyboard with a gap
- hidden behind the keyboard
- left behind after the keyboard closes

The page also jumps back to the caret when the user scrolls away. And the
toolbar has no tools for the database, Journal Todo and reference features in
[pr/18](../pr-18/) and [pr/19](../pr-19/), so on a phone those are only
reachable through the slash menu, if at all.

## What changes

### Placement

- **The toolbar sits on the keyboard.** It follows the live keyboard height,
  as the keyboard opens, closes and changes height.
- **Viewport pans.** The toolbar is re-placed when iOS pans the visual
  viewport without resizing it.
- **No double offset.** The keyboard height is no longer counted twice, and
  the tab bar's padding is dropped while the keyboard is open.
- **A stable height baseline.** The window height is re-latched once the
  keyboard is known to be closed. The keyboard height is no longer derived
  from viewport scroll events.
- **The bottom tab bar** follows the keyboard too.
- **Scrolling:**
  - The tapped line stays visible above the toolbar when the keyboard opens.
  - The page isn't pulled back to the caret on every touch, or to a selection
    the user has scrolled away from.
- **Keyboard button.** The "+"/keyboard button really hides and restores the
  keyboard.
- **Panels.** Dragging the window and scrolling toolbar panels work.
- **Preview pages.** The toolbar works in a preview (peek) page.

### Database and reference tools

A database tool group in the toolbar:

- Calendar view
- Journal Todo
- New Journal Todo Table (with the offer to copy undone tasks from
  [pr/19](../pr-19/))
- New note
- Reference
- indent and outdent for List-view rows

## How it works

- `widgets/keyboard-toolbar`:
  - placement maths in `utils.ts`
  - the tool config in `config.ts`
- `apps/mobile/src/virtual-keyboard-provider.ts` reports the keyboard height
  from `visualViewport` resize events against a latched baseline.
- `app-tabs/keyboard-offset.ts` moves the tab bar.
