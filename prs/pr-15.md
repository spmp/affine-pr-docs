# pr/15: Frames in Markdown and HTML export and import
{: .no_toc }

## Why

Exporting a page to Markdown or HTML drops its frames and frame embeds, so
diagrams are lost. Importing that file back can't restore them.

## What changes

- **Export.** Markdown and HTML export write each frame and frame embed as a
  PNG image carrying the frame metadata from [pr/14](../pr-14/).
- **Import.** Importing that Markdown or HTML recreates the frames, placed
  where they were on the canvas.
- **Copy as Markdown** includes frames.

<!-- IMAGE: a page with a frame embed, exported to Markdown and re-imported -->

## How it works

- New Markdown and HTML adapters for `affine:frame` and `affine:surface-ref`
  (`adapters/markdown.ts`, `adapters/html.ts`). They are registered in each
  block's store extension.
- `use-export-page.ts` renders the frame images during export.
- The import dialog passes the images through to the adapters.
