## Why

Fine control, such as exact size, rotation, label offset or arrowhead size,
is spread across small toolbar popovers or not available at all. Diagram
tools usually have a properties panel.

## What changes

- **A properties panel with every changeable setting** of the selected shape
  or connector, including some that have no toolbar control. Two ways to open
  it:
  - **Properties** in the `…` (more) menu of the shape or connector
    toolbar. It opens as a floating panel next to the toolbar.
  - **The right sidebar's properties tab** on the page, which follows the
    current selection.

  It has one place for:
  - **Geometry:** position, size, rotation, aspect lock, flip horizontal and
    vertical
  - **Style:** fill, gradient (on, end colour, direction), border style and
    width, corner radius, shadows (box, film, floating, paper), roughness
  - **Text:** font family, size, weight and style; text resizing (auto width,
    auto height, both)
  - **Connector:** type, line style, end styles, endpoint scale, jump type and
    size, label position, offset and anchor
  - **Grid anchor**
- **Endpoint scale works.** It now changes the size of arrowheads and other
  markers. Before, the value was written but never drawn.

## How it works

- The panel is `blocks/root/src/edgeless/configs/toolbar/properties-modal.ts`.
  The `…` menu entry (`configs/toolbar/more.ts`) shows it for a single
  selected element. The detail page's right sidebar tab
  (`object-properties.tsx`) hosts the same panel.
- `ConnectorElementModel` gets `frontEndpointScale` and `rearEndpointScale`
  accessors. Marker sizes in `renderer/utils.ts` use the scale.
- `TextResizing` gains `NONE` and `AUTO_WIDTH`. They are added at the end,
  because it is a persisted numeric enum and inserting them would shift
  existing values.
