## Why

AFFiNE's edgeless mode has four basic shapes: rectangle, rounded rectangle,
ellipse and triangle (the diamond is also available). Flowcharts,
architecture sketches and mind maps need many more.

## What changes

- **About 60 new built-in shapes:**
  - **Flowchart:** process, decision, data, document, multi-document,
    terminator, preparation, manual input and operation, delay, merge, sort,
    collate, loop limit, display, off-page reference, stored and internal
    storage, database, sequential and direct data, card, paper tape, summing
    function, or, annotations
  - **Arrows:** up, down, left, right, two-way, bent, notched and callout
    arrows
  - **General:** callout, cloud, cube, cylinder, hexagon, parallelogram,
    trapezoid, step, tape, actor, document, logic AND and OR, right triangle
  - **Containers and lists:** container, vertical and horizontal containers,
    list
  - **Mind map:** central idea, sub-topic, square, organisation, division
- **A shape browser.** A searchable panel of every shape, opened from the shape
  tool. Its width stays fixed while you search, and search focus works in peek
  view.
- **Richer edge anchors.** Each shape type has its own connection points.
- **"Next shape" in flowcharts.** It uses the shape's real bounds, so
  generated shapes are spaced evenly.
- **Style memory per shape type.** Each shape type remembers its last style.

## How it works

- Each new shape is a path renderer under
  `gfx/shape/src/element-renderer/shape/`, with an overlay for drawing under
  `gfx/shape/src/overlay/`.
- Shapes that come from draw.io stencils go through `drawio/stencils.ts` and
  `stencil-shape.ts`.
- `shape-browser-panel.ts` is the browser.

## Testing

- Unit tests: `shape-browser-library.unit.spec.ts`.
- E2E: the shape browser specs.
