## Why

Diagramming tools such as draw.io set the expectation for connectors:
rounded orthogonal corners, line jumps where lines cross, manual waypoints,
and a wide choice of arrowheads, including ER-diagram notation. AFFiNE's
connectors have straight or curved paths and a handful of endpoint styles.

## What changes

- **Rounded orthogonal connectors.** A `Rounded` connector mode with a
  configurable corner radius (default 20).
- **Line jumps.** Where two connectors cross, one can hop over the other. Jump
  style and size can be set.
  - A crossing exactly at the other connector's corner is not drawn as a jump,
    for example where two connectors run together and then split.
- **Waypoints.** A connector can route through manual waypoints.
- **Many more endpoint styles:**
  - classic, open, block (normal and thin variants)
  - oval, diamond, box, half-circle, async
  - dash, cross, circle, circle-plus
  - ER notation: one, mandatory-one, many, one-to-many, zero-to-one,
    zero-to-many
- **Endpoint scale.** The size of each end's marker can be set separately.
- **A dense connector menu** gives quick access to these options.
- **Label editing** and the connector settings page are updated to match.

## How it works

- `ConnectorElementModel` gains these fields:
  - `cornerRadius`
  - `waypoints`
  - `jumpStyle` and `jumpSize`
  - `frontEndpointScale` and `rearEndpointScale`
  - a local `routedPoints`
- `jump-calculator.ts` finds the crossings between connector segments and
  ignores intersections at either connector's own endpoints.
- `connector-watcher.ts` keeps jumps up to date as elements move.
- Rounded paths are drawn in `renderer/utils.ts`. The default radius comes
  from a single constant, `DEFAULT_CONNECTOR_CORNER_RADIUS`.
- `connector-manager.ts` is split so later branches (flips, grid snapping) add
  to it without conflicts.

## Testing

- Unit tests: `jump-calculator.unit.spec.ts`, covering a false positive at a
  shared corner and a real X-crossing.
- `ConnectorSchema` tests check that `cornerRadius` is required and defaults to
  20.
- Integration test: `last-props.spec.ts`.
