## Why

The mobile settings screen has a handful of options: theme, font and
language. Everything else, such as editor and edgeless defaults, palettes,
due-date highlighting and workspace settings, can only be changed from a
desktop.

## What changes

The mobile settings screen gets an entry that opens the **full desktop
settings menu**, laid out for a phone.

Sections that make no sense there, or that the mobile screen already covers,
are hidden:

- account
- plans
- billing
- about
- experimental features
- keyboard shortcuts

## How it works

- `mobile/dialogs/setting/full-settings` hosts the desktop settings dialog.
- `isTabShownOnMobile()` in `desktop/dialogs/setting/mobile-tabs.ts` filters
  the sidebar.
- Styles adapt the sidebar and panels to a narrow screen.
