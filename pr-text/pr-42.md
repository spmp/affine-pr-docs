## Description

Developer-only tooling for debugging on a real device without a remote
inspector. Both parts are off unless enabled in server config:

- **Debug-log upload:** signed-in users only.
- **Token-gated remote eval:** the app polls for a snippet, runs it and posts
  back the result.

Includes a CLI helper and a workflow doc.

Full write-up and testing notes: https://spmp.github.io/affine-pr-docs/pr-42/
