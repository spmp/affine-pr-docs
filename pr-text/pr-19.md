<!-- Title: feat(database): task hierarchy, List view and the Journal Todo -->
Makes a database work as a to-do list, and adds a **Journal Todo**: one task
table shown on every journal page, filtered to the day.

- **To-do lists:**
  - parents tick when all children are ticked, and untick when one is
    reopened
  - per-list settings: optional fields, layout, status mapping
  - keyboard indent and outdent
  - to-do list → database, keeping order, hierarchy and fields
- **Databases as task lists:**
  - hierarchy in Table and Kanban views
  - parent status rules: Done roll-up, In Progress promotion, auto-demote,
    manual Done cascade (per table, with global defaults)
  - Kanban columns, filter by level, show children or descendants
  - move a table to another page
- **Settings → Editor → List, Database, and Kanban** for the global defaults.
- **List view:**
  - native list editing: Enter, Backspace and Delete merge/split, indent,
    undo, select-all
  - drag rows like to-do items
- **Database references with their own views and filters.**
- **Journal Todo:**
  - use an existing table as the source, or create one
  - a new table can take over the previous one's unfinished tasks
  - works from journal templates
  - due dates on Calendar, with an overdue highlight
  - notes on tasks
- **Mobile:** touch support for List and Calendar views. Mobile database
  editing is on by default.
- **Performance and data safety:**
  - Cells are written in place. Whole-table rewrites grew a real doc to
    116 MB.
  - Filters read only their own columns.
  - Drags write only the changed cells.
