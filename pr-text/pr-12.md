<!-- Title: feat(edgeless): properties panel for shapes and connectors -->
A **properties panel** in the right sidebar for the selected shape or
connector. It covers:

- geometry
- fill and gradient
- border
- shadow
- text
- connector routing, ends, jumps and label

Endpoint scale now changes marker size; before, it was stored but never
drawn. `TextResizing` gains `NONE` and `AUTO_WIDTH`. They are appended,
so existing values keep their numbers.

Screenshots and details: https://spmp.github.io/affine-pr-notes/pr-12/
