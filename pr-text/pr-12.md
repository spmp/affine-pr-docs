## Description

A **properties panel** with every changeable setting of the selected shape or
connector. Open it from **Properties** in the toolbar's `…` menu, or from the
right sidebar. It covers:

- geometry
- fill and gradient
- border
- shadow
- text
- connector routing, ends, jumps and label

Endpoint scale now changes marker size; before, it was stored but never
drawn. `TextResizing` gains `NONE` and `AUTO_WIDTH`. They are appended,
so existing values keep their numbers.
