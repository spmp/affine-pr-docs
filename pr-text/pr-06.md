## Description

Hovering a shape shows its connection anchors. Dragging from an anchor starts
a connector at that point, without picking the connector tool first.

- Only the shape under the pointer shows anchors.
- Typing in notes is not affected.
- *Settings → Connector → Hover to initiate* turns it off.
