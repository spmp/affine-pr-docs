## Description

Adds the `compression` middleware, so a self-hosted server without a
compressing proxy compresses its responses. It covers:

- **Static assets.** Registered first in
  `StaticFilesResolver.onModuleInit`, because those routes are registered
  before `server.ts` runs.
- **API responses.**

Full write-up and testing notes: https://spmp.github.io/affine-pr-docs/pr-40/
