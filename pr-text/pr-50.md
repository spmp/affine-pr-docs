<!-- Title: perf(store): look up block parents and the root from a cached index -->
`store.getParent()` and the root lookup scanned every block in the doc on
each call. On a 500-paragraph page that was about a third of the JavaScript
per keystroke. A full re-render was quadratic.

They now use a cached child → parent index. The index is dropped on any
structural change: the store API, plus a Yjs `beforeObserverCalls` hook for
remote updates and undo. It is rebuilt lazily. No behaviour change; unit
tests included.

Profile and details: https://spmp.github.io/affine-pr-notes/pr-50/
