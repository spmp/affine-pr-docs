## Description

When a settings schema gains a new required field, the persisted value stops
validating and `EditorSetting.watchAll()` resets the **whole** entry to its
default. Every customisation under that key is lost, not just the missing
field.

This PR merges the stored value onto the schema defaults before validating.
Only the missing field gets its default. A full reset now happens only for data
that still fails to validate, such as corrupt values.

- `parseSettingWithFallback()` extracted from `watchAll()`, with unit tests.
- Uses the same pattern as `edit-props-store.ts`.

Full write-up and testing notes: https://spmp.github.io/affine-pr-docs/pr-00/
