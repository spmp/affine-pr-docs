## Description

Mobile settings get an entry that opens the full desktop settings, laid out
for a phone. Sections the mobile screen already covers, or that don't apply,
are hidden: account, plans, billing, about, experimental features and
shortcuts.

![Demo](https://spmp.github.io/affine-pr-docs/assets/images/pr-31/hero.webp)
