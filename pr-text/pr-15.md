## Description

Markdown and HTML export include frames and frame embeds, as PNGs carrying
frame metadata. Importing the file recreates the frames. Copy as Markdown
includes them too.

![Demo](https://spmp.github.io/affine-pr-docs/assets/images/pr-15/hero.webp)
