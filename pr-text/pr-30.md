## Description

On iOS (Safari and the installed PWA), the keyboard toolbar now follows the
live keyboard height. It handles:

- viewport pans
- a closed keyboard
- the tab bar

The page no longer jumps back to the caret on every touch.

Adds a database tool group:

- Calendar view
- Journal Todo
- New Journal Todo Table
- New note
- Reference
- List-row indent and outdent

Tested on iPhone; covered by unit and mobile-viewport integration tests.
